Tokyo Snow

A warm, dark theme sampled from a single photo: a snowy Tokyo alley at night, lit only by a row of vending machines. The lit machines and signs give it reds, oranges and golds. The snow under green-tinted light gives it sage, moss and pine. The shadowed walls and pavement become the backgrounds.

        Variants

        Three levels of glow

        The extension ships three themes. They share every colour name and hue, and give each colour the same job. Only the brightness and saturation change.

        Install

        Get it in a minute

        1. Open the Extensions view in VS Code and search for Tokyo Snow by MatthewGadsden.
        2. Click Install.
        3. Press Ctrl+Shift+P (Cmd+Shift+P on Mac) and run Preferences: Color Theme.
        4. Choose Tokyo Snow, Tokyo Snow Neon Alley or Tokyo Snow Vending Glow.

        It's on the Visual Studio Marketplace for VS Code and on Open VSX for VSCodium and Code - OSS. Every GitHub release also has the .vsix attached.

        VS Code code --install-extension MatthewGadsden.tokyo-snow-vs
        VSCodium codium --install-extension MatthewGadsden.tokyo-snow-vs
        From a release code --install-extension tokyo-snow-vs-1.1.0.vsix

        Contributing

        Issues and pull requests are welcome on GitHub. If you change a colour, keep it inside the 13-colour palette. Edit only themes/tokyo-snow-color-theme.json, then run python3 themes/generate-variants.py to regenerate Neon Alley and Vending Glow from it.
